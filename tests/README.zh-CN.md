# 分支构建和源码核验

这些测试覆盖此次增加的发布包装工具，不替代冻结固件的链接回放，也不访问硬件。

```powershell
python -X utf8 -B tests/test_branch_tools.py
```

13 项测试检查错误型号和版本指纹、源码变动或缺失、危险或重复归档路径、清单变化及已有输出目录。一个不可执行的输入夹具保留在 `build/tests/` 中。

`build.py` 在独立 Python 进程中执行本型号的原厂提取和链接回放，再将镜像及更新器与固定 M2 SHA-256 比较。完整的 125 文件共享源码闭包保持原样，由本分支 `release_profile.json` 锁定支持的目标。按照根目录命令重建时，只需提供本型号指纹固定的原厂更新器。

生成日志可能含本机路径。对外发布脱敏的 `build_verification.json`，不要直接发布整个 scratch 或 artifacts 目录。

冻结的 `firmware/` 目录还包含历史探索工具和多型号测试，并非每份探索脚本都能单独运行。单型号重建请使用根目录说明中的入口。
