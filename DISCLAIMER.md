# Original-firmware analysis disclaimer

English | [简体中文](DISCLAIMER.zh-CN.md)

Developer: **Caimankekw**. This branch contains unofficial analysis and read-only extraction tools for Nikon Air Remote TTL-N C5. Recovered pseudocode and hardware interpretations may be incomplete or inaccurate. They are not the manufacturer's complete source, approval or certification.

The tools read a user-supplied original updater as data and create local analysis files. They do not execute the updater or write a device. The partial BIN has unknown bytes and must not be flashed directly. Passing extraction, CRC or roundtrip checks does not prove all recovered behavior or hardware compatibility. Applying these findings to hardware or custom firmware can cause device malfunction, settings loss, synchronization/exposure errors and other losses.
