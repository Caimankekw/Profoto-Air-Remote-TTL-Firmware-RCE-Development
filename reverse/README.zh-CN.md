# Nikon C5 原厂固件逆向说明

本目录整理 **Air Remote TTL-N C5** 的有限范围原厂逆向结果。[original.pseudocode.c](original.pseudocode.c) 是带地址证据、人工编写的类 C 伪代码，**不是厂家完整 C 源码，不能编译成原固件，也不能刷入设备**。函数名、类型和结构化流程是为便于理解而重建的表达；不透明调用表示此处尚未恢复的实现。

[English](README.md)

| 文件 | 内容 |
| --- | --- |
| [model.json](../model.json) | 原厂 stock 身份配置的逐字节副本，含更新器、HEX、稠密镜像的指纹和提取偏移 |
| [original_contract.json](original_contract.json) | 精选的原 RAM、界面、时钟、无线和 NVM 事实 |

本目录不包含更新器 EXE、固件 BIN/HEX、大型反汇编、设备采集或工作站绝对路径。来源记录中的相对路径只标识先前研究材料，不是本分支的运行依赖；精选事实已写入公开的 contract 和 source map。要从固件复核，需另行取得与 `model.json` 指纹匹配的原更新器，并使用仓库公共只读检查工具。

## 已恢复的边界

| 范围 | 原厂锚点 | 证据支持的结论 |
| --- | --- | --- |
| 启动与主循环 | `4102 → 417E → 56DE`、`4CF6` | 运行时初始化、原前台调用顺序和相机门控 |
| 时钟 | `7124`、`716E..7174` | RAM `11B:11C` 全 16 位计数；严格 `delta > divisor`，更新后丢弃余数 |
| 按键 | `4D44`、`8E62`、`4ECC`、`9BA6` | 11 个四字节对象、保留 bit 7 的历史移位、三样本消抖、250/650 计数阈值 |
| 原三组界面 | `946E → 5986`、`6928`、`6F44` | A/B/C 与 ALL 选择、TTL 补偿或手动相对值、原有符号十分位绘制 |
| 无线 | `6ECC → 8FB0 → 9D54`、`5E34` | 相对调节命令、零标记加 16 字节记录、普通 `RSGT1` 传输 |
| NVM | `6088..609E → 7FC4`、`91C2`、`9B0E` | 原 journal 描述符及 Flash 字写入、擦除原语 |
| 相机与时序 | `4108`、`5D74`、`65C2`、`6CD0`、`9A02`、`A0AE`、`A77A` | 已观察的中断、相机状态、脉冲和接收入口；**不是完整 HSS 算法** |

地址均为十六进制 PIC18 **字节地址**。JSON 区间包含起点、不包含终点；source map 的区间是取证范围，不自动等同于整函数。区间散列与入口字节直接从原厂 stock 镜像读回；语义摘要还依据静态解释和已标识的研究输入。伪代码省略寄存器破坏范围、调用约定和部分副作用，数字显示段明确只表达取值逻辑。

原模式对象通常位于 RAM `01B1`，指针为 `49:4A`；`0=TTL`、`1=MAN`，A/B/C 补偿位于对象偏移 `4..6`。原手动相对值位于 `99..9B`，HEAD `4C` 和 MODEL `50` 的低三位对应三组。原界面只有三组；没有把新增六组状态、组合键策略、绝对功率命令、hook、适配层或新存储格式当作原厂功能。

原队列容量为 100 字节，普通记录占 17 字节，因此已用量不大于 83 时才能接收。`9D54` 成功只说明本地入队，不代表接收器确认、射频完成或曝光成功。原 `7A12` 的 FEC 命令 `25` 与手动相对命令 `06/07/0D/0E` 分开。

## 证据与未恢复部分

`4000..4001` 仍未知，两个零只是占位。`[4002,10000)` 是直接变换范围；`[10000,1FC00)` 的 FF 填充来自本固定更新器系列的 opaque 高地址尾部指纹匹配，**不能称为任意高地址解密**。稠密 partial 镜像为 113,664 字节，包含未知首字占位。`model.json` 原样保留 stock-only 配置；其中 `air2_port_implemented: false` 描述的是该原厂快照。

约 1 kHz 只是从时钟与除数配置得出的设计推断，没有实测毫秒标定。`7FFF` 掩码属于另一条编码截止时间路径，不属于原 16 位 tick。额外 PORTE.1 输入的实体用途尚未确认。

原 journal 逻辑范围是 `[1F800,1FC00)`，完整槽选择、提交和恢复状态机尚未在此恢复。Flash 原语返回时无条件置位 `FD0.7` 和 `FF2.7`，不是恢复进入前的中断使能状态；这些材料不证明物理擦除几何或断电行为。

相机/HSS 入口及部分字节区间不等于完整 HSS 算法恢复，也不证明实际时序等价。本次公开整理没有执行更新器，没有访问设备、USB、相机或无线，也没有进行曝光测试；不声称取得完整厂家源码树、原构建系统或完整 bootloader。
