# Olympus A4 原厂固件逆向

[English](README.md) · [身份信息](../model.json) · [精简原厂契约](original_contract.json) · [证据索引](provenance.json)

本分支记录 **Air Remote TTL-O A4** 的部分原厂行为。C-like 文件是说明性逆向伪代码，**不是厂家完整 C 源码，也不能编译成固件**。`native_*` / `opaque_*` 保留尚未展开的原厂内部逻辑。AIR2-M2 开发属于独立分支。

| 模块 | 原厂程序字节地址 | 范围 |
|---|---|---|
| [键盘与时钟](pseudocode/keyboard_clock.c) | `5036`、`92FC`、`9DF4`、`596E`、`AB2E`、`669C` | 采样历史/标志、250/650 计数回调、时间戳语义 |
| [三组 UI](pseudocode/ui_abc.c) | `6A62`、`98D8→609A`、`86D6`、`742E`、`688E`、`A10E` | TTL/MAN、A/B/C/ALL、原厂值范围、LCD ABI |
| [无线队列](pseudocode/radio.c) | `ABD8`、`919E`、`9F1E`、`936C`、`82B0` | 类型 2、原厂准入、16 字节主体与标记 |
| [启动与 NVM](pseudocode/nv_startup.c) | `69CA`、`5E1C`、`5520`、`A66C`、`962C`、`9E1A` | 启动次序、日志位域、写入行为 |
| [相机/HSS 边界](pseudocode/hss_boundaries.c) | `4108..4178`、`67E8..688E`、`466A`、`75AC`、`8A92` | IRQ、相机接收与强制模式调用边界 |

`VERIFIED` 表示原指令、固定原始字节或引用的离线审计支持；`INFERRED` 表示物理键名、步进单位等语义推断；`UNKNOWN` 表示尚未闭合。任何分类均不代表相机、RF、灯具或 HSS 实机验证。

原厂 `9F1E` 向 `919E` 请求的是 **16 字节**，条件为 `requested <= 31 && count + requested < capacity`，随后加入标记 0 和 16 字节主体。额外 17 字节预检属于 AIR2。原厂写入/擦除函数在启动操作后无条件置位 `FD0.7` / `FF2.7`，不保存旧状态。`7F7E` 超时只适用于 MAN；扩展到 TTL、D/E/F 页面、模式切换前临时禁止无线，以及重新投影开机 pending 标志均属于开发版行为。

`model.json` 原样保留 stock profile。分析映像为 `[0x4000,0x1FC00)`；首字 `[0x4000,0x4002)` 未知，零占位不是恢复的指令。参考解码器读取 `[0x4002,0x10000)`；`[0x10000,0x1FC00)` 的 FF 判定依赖不透明编码与已知 FF 参考的指纹匹配，并非独立解码。低于 `0x10000` 的最后非 FF 结束位置为 `0xABF0`（不含），不能证明可执行范围或空闲 Flash 所有权。索引内所有证据窗口均位于解码范围。

证据索引给出原工作区相对来源、SHA-256，以及从固定 stock 分析映像计算的半开地址窗口哈希。来源路径用于追溯，不是运行依赖。这里只摘要审阅过的指令窗口；候选线性 listing 可能把数据误解成代码。本包不含厂家 EXE/HEX/BIN、大型 listing 或设备采集。

整理过程中没有运行 EXE、设备、USB 或网络操作。250/650 不能直接称为毫秒；完整 HSS 时序、模拟多键行为、bootloader 所有权和未证中断嵌套仍未知。AIR2 的资格结论不构成原厂固件证明。
