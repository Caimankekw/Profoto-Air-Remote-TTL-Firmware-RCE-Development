# Sony A6 原厂固件逆向说明

本目录整理 **Air Remote TTL-S A6** 的有限范围原厂逆向结果。[original.pseudocode.c](original.pseudocode.c) 是人工编写、带地址证据的类 C 伪代码，**不是厂家完整 C 源码，不能编译成原固件，也不能刷入设备**。名称、类型和结构化流程是解释性重建；不透明调用明确保留尚未恢复的边界。

[English](README.md)

| 文件 | 内容 |
| --- | --- |
| [model.json](../model.json) | 原厂 stock 身份配置的逐字节副本及提取指纹 |
| [original_contract.json](original_contract.json) | 精选的原 RAM、按键、界面、时钟、队列与 NVM 事实 |

| [provenance.json](provenance.json) | 输入指纹、摘录方法及旧候选文件的范围核对 |

本目录不包含更新器 EXE、固件 BIN/HEX、大型反汇编、设备采集或工作站绝对路径。来源路径只标识先前研究输入，不是本分支的运行依赖；精选事实已保存在公开 contract 和 source map 中。要从固件复核，需另行取得指纹匹配的原更新器，并使用仓库公共只读检查工具。

## 已恢复的边界

| 范围 | 原厂锚点 | 证据支持的结论 |
| --- | --- | --- |
| 启动与主循环 | `4102 → 4252 → 6174`、`4D42`、`4E94` | ROM 初始化、板级/对象入口与前台调用顺序 |
| 时钟 | `6972`、`69CC..69D8` | RAM `106:107` 全 16 位计数；严格 `delta > divisor`，更新后丢弃余数 |
| 按键 | `4EE2`、`930E`、`5348`、`A0C8` | 11 个四字节对象、三样本消抖、250/650 计数阈值 |
| 原三组界面 | `5CD8`、`6DDE`、`7584`、`51DE` | A/B/C 或 ALL、原相对值/补偿值、LCD 快照和串行服务 |
| 无线 | `7490 → 9516 → A158 → 5C08 → 5DA4` | 相对命令构帧、原队列和普通 `RSGT1` 串行封装 |
| NVM | `835E`、`81A6`、`9840`、`9FE4` | 描述符、逻辑槽地址算术和 Flash 原语 |
| 相机/HSS 边界 | `4108..4252`、`6BB0..6DDE`、`A586..A5E8` | 已观察的中断、相机与独占无线区间；**不是完整 HSS 算法** |

地址为十六进制 PIC18 **字节地址**。JSON 区间包含起点、不包含终点；source map 的区间是选定取证范围，不自动等同于整函数。散列与短入口签名已从原厂 stock 字节读回；语义标签还依赖静态解释和已标识的研究输入。伪代码省略调用约定、寄存器破坏范围和部分副作用；数字显示段只是取值示意，不是可替换的渲染程序。

原模式对象位于 RAM `0193`，指针为 `D2:D3`，`0=TTL`、`1=MAN`。原 FEC 位于 `197..199`，手动相对值位于 `EC..EE`，选择器 `C1` 取 `1/2/3/7`。HEAD `DB`、MODEL `F3` 使用低三位；原 ALL 选择会清除选中框。数据包层能接收某组号，不等于原界面支持六组。本材料没有把新增六组策略、绝对功率命令、hook、适配层、组合键或新 NVM 格式视为原厂能力。

`E6..EB` 队列描述符使用 `[0400,0464)` 的 100 字节缓冲。普通记录为零标记加 16 字节帧，已用量不大于 83 时才可接收。`A158` 从 `076` 取得 bank 0 源地址；成功只表示本地入队，不是接收端确认。该例程不屏蔽中断，而有限 ISR 直接流审计能到达其他生产者和中止函数，因此不能假定整条记录原子提交。`D8` 仅是已观察的独占无线门控，不能证明所有相机忙阶段。

## 证据与未恢复部分

`4000..4001` 仍未知，零值只是占位。`[4002,10000)` 为直接变换区域；`[10000,1FC00)` 的 FF 填充来自本固定更新器系列的 opaque 尾部指纹匹配，**不能称为任意高地址解密**。`model.json` 原样保留 stock 配置，`air2_port_implemented: false` 属于该原厂快照。

旧候选覆盖 `[4000,10000)`，49,152 字节，SHA-256 为 `b5d7c9b199cc1a705514c028d609e31bb8b6fb55813cdc2ab1fcba898be7cee5`。共享 stock 覆盖 `[4000,1FC00)`，113,664 字节，SHA-256 为 `abed888029102baea3a3f003ee40d8ab27119a3b1c3ff988342dbfaf8437984b`。已逐字节核对已知重叠区 `[4002,10000)` 完全相同；整文件散列不同是范围和长度不同，两个文件的未知首字均未恢复。

原计数不能标作实测毫秒。250 计数回调 `AF5A` 是直接返回，650 计数路径为 `A134 → 6A96`；阈值回放使用回调边界，未证明完整的重复长按节奏。`DC` 尚不能命名为频道编辑状态。

原 journal 逻辑区间为 `[1F800,1FC00)`：256 个四字节槽，从 `1FBFC` 向低地址排列。逻辑寻址不证明物理擦除几何或完整提交/恢复行为。Flash 原语返回时无条件置位 `FD0.7` 与 `FF2.7`，不是恢复原中断状态。

ISR 审计是直接控制流的保守超集，不是输入可达性、任意运行时控制流或实际 HSS 正确性的证明。`4250` 是 fast return；`41B8` 是一条调用指令的第二字，不是独立 ISR 入口。本次整理没有执行更新器、访问硬件或 USB，也没有相机、射频或曝光测试。完整厂家 C 源码、完整 bootloader 及完整 HSS 算法均仍在已恢复范围之外。
